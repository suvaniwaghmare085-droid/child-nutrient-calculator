# 🥗 Child Nutrient Calculator

## 📌 Project Overview

The **Child Nutrient Calculator** is a Python-based application designed to calculate a child's Body Mass Index (BMI), estimate daily calorie recommendations based on age groups, and track calorie intake from different food items.

The program collects basic information about the child, calculates food-wise calorie consumption, and generates a detailed nutrition report.

## ✨ Features

- **User Information:** Collects the child's name, age, gender, height, and weight.
- **Input Validation:** Ensures valid numerical inputs and prevents empty text entries.
- **BMI Calculation:** Calculates BMI using height and weight.
- **Age-Based Calorie Recommendations:** Estimates daily calorie requirements according to predefined age groups.
- **Food Calorie Tracking:** Calculates calories consumed from six food categories.
- **Nutrition Report:** Displays personal details, BMI, food-wise calorie intake, and total calories.
- **Calorie Comparison:** Compares total calorie intake with the predefined daily recommendation.

## 🍎 Food Categories

The application uses predefined calorie values per 100 grams:

| Food Item | Calories per 100g |
|---|---:|
| Milk | 100 |
| Egg | 155 |
| Rice | 130 |
| Lentils | 113 |
| Vegetable | 85 |
| Meat | 143 |

## 📊 Age-Based Calorie Recommendations

| Age Group | Daily Calories |
|---|---:|
| Below 2 years | 800 |
| 2–4 years | 1400 |
| 4–8 years | 1800 |

These values are simplified assumptions specified for the project.

## 🖥️ How It Works

1. Enter the child's personal details.
2. Provide height and weight.
3. The program calculates BMI.
4. Enter the quantity of each listed food consumed in grams.
5. The program calculates the calories for each food item.
6. A nutrition report displays the total calorie intake and compares it with the predefined recommendation.
